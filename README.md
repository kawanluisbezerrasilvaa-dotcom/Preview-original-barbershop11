# GOAT Barber Shop — site de prévia

Versão visual atualizada: fundo preto puro, textos brancos, efeitos neon brancos e logo 3D reposicionada à direita para não cobrir o título GOAT. Os links, navegação, avaliação, endereço, horários e interação da logo 3D foram preservados.

## Como iniciar no Windows / PyCharm

1. Extraia o ZIP inteiro.
2. Abra a pasta `goatpreview-site` no PyCharm (a pasta onde está `package.json`).
3. Abra o Terminal e execute `npm install`.
4. Quando terminar, execute `npm run dev`.
5. Abra o endereço local exibido pelo Vite, normalmente `http://localhost:8080/` ou `http://localhost:5173/`. Use o endereço exato que aparecer no terminal.
6. Mantenha o terminal aberto enquanto usa o site.

### ZIP com selo
Inclui o selo vermelho de prévia na lateral superior direita da imagem principal.

### ZIP sem selo
É a mesma versão do site, com as mesmas páginas e funcionalidades, mas sem exibir nem incluir o arquivo do selo vermelho.

O selo visual identifica que a página é uma prévia, mas não impede tecnicamente cópias do código ou do design.
